# AI Resume Improver & Student Career Growth Tracker

An AI-powered resume analysis and student career development application built using Python and Streamlit. It helps students analyze resumes, identify skill gaps, track academic skills and improve their career readiness.

## Features

- Upload resumes in PDF format
- Automatic resume text extraction
- Skills coverage and job-description keyword matching
- ATS-friendly resume evaluation
- Semester-wise skill rating and evidence tracking
- Project portfolio tracking
- Career-based skill-gap recommendations
- Resume section checklist and bullet-point improvement
- Faculty matching based on skill gaps
- Instant resume feedback

## Technologies Used

- Python
- Streamlit
- NLP
- PyPDF2
- pdfplumber
- Scikit-learn
- SQLite
- CSV

## Run Locally

1. Clone this repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`

## Data and Privacy

- Student records are stored in a local SQLite database.
- Local database files are excluded from Git.
- Faculty profiles should be verified before being presented as verified matches.

## Limitations

- The first version uses rule-based recommendations.
- Resume improvements are template-based, not generated by an LLM.
- Skill ratings are self-assessments unless independently verified.
